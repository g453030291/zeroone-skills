# monitor-anything

用一句自然语言描述你关注的方向，剩下的交给它：每天自动完成**采集① → 清洗② → 语义筛选③ →
跨源聚类④ → 摘要成文⑤ → 可视化渲染⑥**，产出一份「晨光（Sunrise）」暖色风格的 HTML 日报。
这是一个 AI Agent Skill，接入零一实验室（Lingyi Labs）的资讯数据池，可在 Claude Code / Codex /
Cowork 等支持 Skill 的 Agent 产品里使用。

## 这是什么

- **数据采集**：多渠道（微信公众号、小红书、纽约时报、AI 热点……未来还会增加），有规模
- **数据整理**：去重、清洗噪音、语义理解筛选
- **跨源聚类**：识别「这 5 篇文章在讲同一件事，而且来自 3 个彼此独立的信源」
  （按账号/域名判定，两个不同的公众号算两个信源，不是笼统的「渠道类别」）
- **摘要与洞察**：不是简单罗列标题，而是告诉你「为什么这件事与你相关」

## 快速开始

在支持这个 Skill 的 Agent 产品里，直接说出你想监控的方向即可，例如：

> 帮我盯一下国内 AI 推理基础设施和芯片供应链的动态，我不关心融资八卦和课程广告。

第一次会引导你完成：
1. 自动获取一个 **30 天有效期的试用 token**（不需要你先发邮件——脚本会自动申请并写入本地
   配置；到期后如果还想继续用，再邮件联系 **gems9232@foxmail.com** 申请延长即可）
2. 确认你的关注方向、排除关键词、报告语言（中文/英文）、报告时间、数据保留天数——语言
   选择会真正影响输出：报告正文、界面文案、渠道名字都会用你选的那种语言
3. 直接抓取你自己的真实数据，生成第一份属于你的报告（不再需要先看一遍示例数据——token
   已经自动到位，直接跑真实流程比等一份合成数据更快）

如果 Agent 所在的平台支持定时唤醒（下面「自动化怎么实现」有说明），Setup 最后会帮你建好
之后每天自动生成新报告的机制。每天的报告是一份独立文件 `data/reports/<日期>.html`，
单文件、双击即开、可以直接发微信分享——分享一份报告就是分享这一个文件，不会带出别的
日期或别的关注点的内容。另外还有一份固定不变的首页 `data/reports/dashboard.html`，
是纯粹的日期目录，点日期进去就是当天那份报告，方便你自己回看历史，这份首页本身不会被
分享、也不参与上传。每天生成报告后还会自动上传当天那一份文件，换取一个可以在浏览器直接
打开的公开链接（不用你开口要），报告页上的「分享今日洞察」按钮点击就是复制这个链接——
详见下面「分享报告」和「数据存放与隐私」。

## 自动化怎么实现

这个 Skill 本身没有后台进程，"每天自动"靠的是 Agent 所在平台的定时任务能力（比如
Claude Code、Codex、Cowork 等产品提供的"定时唤醒 Agent 执行一段任务"机制，具体叫法和用法
因平台而异）。Setup 阶段结束时，Agent 会尝试帮你创建两条独立的定时任务：

- **采集任务**：一天触发几次（默认 0/6/12/18 点），只做一件事——运行 `harvest.py`
  抓新数据，不需要语义推理，几秒钟跑完。多次采集是为了给 24 小时窗口留冗余，单次网络
  抖动不会丢数据。
- **报告任务**：一天一次，触发时间就是你在 Setup 时确认的报告时间，唤醒后 Agent 会
  完整跑一遍筛选、聚类、摘要、渲染，随后按默认流程上传分享链接。

如果你所在的平台不提供这种定时唤醒能力，Agent 会明确告诉你，不会假装设置成功——这种
情况下需要你自己想起来的时候手动唤起 Agent 生成报告，`harvest.py` 依然可以手动运行来
积累数据。

## 关于首次配置时的关注方向推断

Setup 阶段会尝试帮你推断关注方向（比如读 `CLAUDE.md`、项目 README、技术栈，或者调用
memory 能力），推断不出来就直接问你三个问题。这里有一条硬性边界：**只读取与工作/技术
背景相关的内容，推断结果必须原文展示给你确认，不会被静默使用。**

## 数据存放与隐私

- 原始抓取内容和中间数据保存在本地 `data/` 目录（SQLite + JSON），**默认保留 30 天**，过期自动清理；
  最终日报的默认上传行为见下文
- `data/` 已加入 `.gitignore`，且 `harvest.py` 启动时会主动检查这个目录有没有被 git 跟踪
  ——抓取的是公众号、纽约时报的全文内容，误提交到公开仓库是真实的版权风险，不能只靠一行
  `.gitignore` 防
- **每天生成的独立报告页 `<日期>.html` 会被自动上传到零一实验室的分享服务，换取一个
  公开链接**（见下面「分享报告」）——这是默认行为，不需要你手动触发，也不是"只有你点了
  分享按钮才会联网"。上传的范围就是这一天这一份文件，不含其他日期或其他关注点；也就是
  说，当天抓取到的资讯标题、摘要、原文链接会离开你的本地机器。上传接口本身不需要你额外
  操作，但如果你不希望每天的内容默认上传到第三方服务，需要知道这一点并自行决定要不要用
  这个 Skill。首页 `dashboard.html`（日期目录）不会被上传，只留在本地
- token 首次使用会自动申请一个 30 天试用版，一个 token 对应一个用户；到期后如需继续使用，
  邮件向 **gems9232@foxmail.com** 申请延长有效期即可，不需要重新走一遍安装流程
- 报告仅供个人阅读筛选使用，不是数据资产项目、不做长期归档、不做搜索引擎（只处理每日增量，
  接口不支持历史回溯）
- 如果某天某个关注方向在数据池里一条都没命中，会自动尝试一次关键词补充检索（同样只取最近
  24 小时内的结果），尽量让报告有实际内容，而不是直接告诉你"今天没有动静"；补充之后依然
  没有才会给出诚实的空报告说明
- **每天独立报告页 `<日期>.html` 内置了百度统计（`hm.baidu.com`）**，任何人（包括你自己）
  用浏览器打开这份报告，浏览器都会加载这段脚本并上报一次访问事件（打开时间、大致来源等
  标准网站访问统计信息，不含报告正文内容）给零一实验室名下的百度统计账号，用来了解报告
  被打开/转发后的实际阅读情况。这段脚本只出现在 `<日期>.html` 里，首页 `dashboard.html`
  没有这段脚本，纯本地打开不会触发上报

## 分享报告

每天报告渲染完之后，Agent 会自动帮你上传一次当天的独立报告页（`<日期>.html`）到零一
实验室的分享服务，换回一个可以直接在浏览器打开、随意转发的公开链接，并把链接写回当天的
报告——**不需要你开口要**。上传范围天生就只有这一天，不会带出其他日期或其他关注点的
内容。打开报告页时点「分享今日洞察」，按钮直接复制这个真链接给你，一个提示"已复制链接，
发给谁都能看"就完事了。

如果那天自动上传恰好失败了（比如网络问题、token 过期），按钮会退化成只复制文案并提示你
让 Agent 重试；跟它说一句"重新生成一下分享链接"即可。

按钮本身依然不会自己联网上传——`<日期>.html` 是会被转发出去的静态文件，把能鉴权的
token 写进它的 JS 里等于把 token 一起发给收到文件的任何人；真正的上传固定由
`scripts/share.py`（Agent 触发）完成，token 不会进到这份 HTML 里。

首页 `dashboard.html`（日期目录）不参与分享——它只在本地帮你回看历史，本身没有分享
按钮，也从来不会被上传。

## 目录结构

```
monitor-anything/
├── SKILL.md              # Skill 入口：触发条件 + 主流程编排
├── ARCHITECTURE.md       # 面向专业用户的设计说明（含架构图、业务流程图、完整文件清单）
├── scripts/               # 零依赖 Python 脚本（采集/清洗/编排/渲染/配置/分享/检索）
│                          #   定时任务不是脚本，由 Agent 在 Setup 时调用宿主平台的
│                          #   调度能力创建，见上面「自动化怎么实现」
├── prompts/                # 筛选/聚类/摘要三个阶段的 LLM 提示词
├── assets/
│   ├── template.html       # 每天独立报告页 <日期>.html 的模板
│   └── dashboard_static.html  # 首页（日期目录）模板，每次渲染都覆盖拷贝一次（无用户数据）
└── data/                   # 本地数据（已 gitignore）：config.json / monitor.db /
                             #   reports/（<日期>.json、<日期>.html、dashboard.html、
                             #   dates-manifest.js）
```

完整的文件清单和每个文件的职责说明见 `ARCHITECTURE.md`。

## 依赖

零第三方依赖，只用 Python 标准库（`urllib` / `sqlite3` / `json` / `hashlib` 等）。不需要
`pip install` 任何东西。
