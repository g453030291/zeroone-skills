# monitor-anything

用一句自然语言描述你关注的方向，剩下的交给它：每天自动完成**采集 → 清洗 → 语义筛选 →
跨源聚类 → 摘要成文**，产出一份深色科技风的可视化 HTML 日报。这是一个 [Claude Skill](https://docs.claude.com/)，
接入零一实验室（Lingyi Labs）的资讯数据池，在 Claude Code / Cowork 等支持 Skill 的产品里直接可用。

## 这是什么

- **数据采集**：多渠道（微信公众号、小红书、纽约时报、AI 热点……未来还会增加），有规模
- **数据整理**：去重、清洗噪音、语义理解筛选
- **跨源聚类**：识别「这 5 篇文章在讲同一件事，而且跨了 3 个渠道」
- **摘要与洞察**：不是简单罗列标题，而是告诉你「为什么这件事与你相关」

## 快速开始

在支持这个 Skill 的 Claude 产品里，直接说出你想监控的方向即可，例如：

> 帮我盯一下国内 AI 推理基础设施和芯片供应链的动态，我不关心融资八卦和课程广告。

第一次会引导你完成：
1. 自动获取一个 **30 天有效期的试用 token**（不需要你先发邮件——脚本会自动申请并写入本地
   配置；到期后如果还想继续用，再邮件联系 **gems9232@foxmail.com** 申请延长即可）
2. 确认你的关注方向、排除关键词、报告时间、数据保留天数
3. 直接抓取你自己的真实数据，生成第一份属于你的报告（不再需要先看一遍示例数据——token
   已经自动到位，直接跑真实流程比等一份合成数据更快）

之后每天会自动生成新的报告，固定文件名 `data/reports/dashboard.html`，单文件、双击即开、
可以直接发微信分享。每天生成报告后还会自动上传一次换取一个可以在浏览器直接打开的公开
链接（不用你开口要），dashboard 上的「分享今日洞察」按钮点击就是复制这个链接——详见下面
「分享报告」和「数据存放与隐私」。

## 关于首次配置时的关注方向推断

Setup 阶段会尝试帮你推断关注方向（比如读 `CLAUDE.md`、项目 README、技术栈，或者调用
memory 能力），推断不出来就直接问你三个问题。这里有一条硬性边界：**只读取与工作/技术
背景相关的内容，推断结果必须原文展示给你确认，不会被静默使用。**

## 数据存放与隐私

- 所有抓取到的内容只保存在本地 `data/` 目录（SQLite + JSON），**默认保留 30 天**，过期自动清理
- `data/` 已加入 `.gitignore`，且 `harvest.py` 启动时会主动检查这个目录有没有被 git 跟踪
  ——抓取的是公众号、纽约时报的全文内容，误提交到公开仓库是真实的版权风险，不能只靠一行
  `.gitignore` 防
- **每天生成的 `dashboard.html` 会被自动上传到零一实验室的分享服务，换取一个公开链接**
  （见下面「分享报告」）——这是默认行为，不需要你手动触发，也不是"只有你点了分享按钮才
  会联网"。上传的是当天渲染好的 HTML 文件本身，也就是抓取到的资讯标题、摘要、原文链接会
  离开你的本地机器；上传接口本身不需要你额外操作，但如果你不希望每天的内容默认上传到
  第三方服务，需要知道这一点并自行决定要不要用这个 Skill
- token 首次使用会自动申请一个 30 天试用版，一个 token 对应一个用户；到期后如需继续使用，
  邮件向 **gems9232@foxmail.com** 申请延长有效期即可，不需要重新走一遍安装流程
- 报告仅供个人阅读筛选使用，不是数据资产项目、不做长期归档、不做搜索引擎（只处理每日增量，
  接口不支持历史回溯）
- 如果某天某个关注方向在数据池里一条都没命中，会自动尝试一次关键词补充检索（同样只取最近
  24 小时内的结果），尽量让报告有实际内容，而不是直接告诉你"今天没有动静"；补充之后依然
  没有才会给出诚实的空报告说明

## 分享报告

每天报告渲染完之后，Claude 会自动帮你上传一次 `dashboard.html` 到零一实验室的分享服务，
换回一个可以直接在浏览器打开、随意转发的公开链接，并把链接写回当天的报告——**不需要你
开口要**。打开 dashboard 时点「分享今日洞察」，按钮直接复制这个真链接给你，一个提示"已
复制链接，发给谁都能看"就完事了。

如果那天自动上传恰好失败了（比如网络问题、token 过期），按钮会退化成只复制文案并提示你
让 Claude 重试；跟它说一句"重新生成一下分享链接"即可。

按钮本身依然不会自己联网上传——`dashboard.html` 是会被转发出去的静态文件，把能鉴权的
token 写进它的 JS 里等于把 token 一起发给收到文件的任何人；真正的上传固定由
`scripts/share.py`（Claude 触发）完成，token 不会进到这份 HTML 里。

## 目录结构

```
monitor-anything/
├── SKILL.md              # Skill 入口：触发条件 + 主流程编排
├── ARCHITECTURE.md       # 面向专业用户的设计说明（含架构图、业务流程图、完整文件清单）
├── scripts/               # 零依赖 Python 脚本（采集/清洗/编排/渲染/配置/定时任务/分享/检索）
├── prompts/                # 筛选/聚类/摘要三个阶段的 LLM 提示词
├── assets/template.html    # HTML dashboard 模板
└── data/                   # 本地数据（已 gitignore）：config.json / monitor.db / reports/
```

完整的文件清单和每个文件的职责说明见 `ARCHITECTURE.md`。

## 依赖

零第三方依赖，只用 Python 标准库（`urllib` / `sqlite3` / `json` / `hashlib` 等）。不需要
`pip install` 任何东西。
